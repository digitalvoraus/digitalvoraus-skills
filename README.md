# digital voraus – Claude Skills

Gemeinsame Skills für Andreas & Sonja.

| Skill | Zweck |
|---|---|
| `dv-ci` | Farben, Schriften, Logo, Layout |
| `dv-social-post` | Posts schreiben, prüfen, planen |
| `dv-kunden-onboarding` | Erstgespräch → Angebot → Kickoff |

## Ändern
Datei auf GitHub bearbeiten → „Commit changes“. In `plugins/digitalvoraus/.claude-plugin/plugin.json` die Version erhöhen (z. B. 1.0.1), dann zieht Claude das Update.

## WUHA (`plugins/wuha`)

| Skill | Zweck |
|---|---|
| `wuha-brand` | Band-Infos, Tonfall, Farben, Märkte |
| `wuha-social-post` | Posts schreiben + via Velocity planen (Woche: IG 3, FB 3, LinkedIn 2, TikTok 2, YouTube 2) |
| `wuha-release-rollout` | Single-/Album-Rollout über alle Kanäle |

Velocity-Connector: claude.ai → Settings → Connectors → *Add custom connector* → `https://www.velocity.li/mcp`
